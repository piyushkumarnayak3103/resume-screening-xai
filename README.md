# Explainable AI Resume Screening System
## Overview
This project presents an Explainable AI (XAI) framework for Intelligent Resume Screening, Skill Gap Analysis, and Job Recommendation.
The system automatically analyzes resumes, predicts suitable job roles, identifies missing skills, and provides transparent explanations for decisions using SHAP.

## Features
- Resume Parsing
- Resume Classification
- Skill Extraction
- Skill Gap Analysis
- Job Recommendation
- Explainable AI using SHAP
- Flask-based User Interface

## Technologies Used

- Python
- Flask
- TF-IDF
- BERT Embeddings
- Random Forest Classifier
- SHAP
- Pandas
- NumPy
- Scikit-Learn

## Dataset

- Kaggle Resume Dataset
- Approximately 2500 resume samples

## Model Performance

| Model | Accuracy |
|---------|---------|
